# DEDA — المصدر الحقيقي لنقاط دوري المتصدرين، مراجعة 28-10-2026

## النتيجة من كود DEDA الأصلي
- `DedaTaskEngine.pointsPerTask=5` نقطة للمهام العادية في مخزن الهاتف.
- المسار الأصلي `task-claim-v1` يضيف **5 نقاط مهمة و20 XP للمستوى و10 قطع اجتماعية** عند المطالبة المعتمدة. لا تُضاف هذه المبالغ مجدداً عند قراءة الدوري.
- الدخول اليومي +10 نقاط محلية والإجابة المرورية الصحيحة +5 نقاط محلية؛ لا يثبت أي منهما حصول 20 XP أصلي. لا يحسبهما عقد الدوري الحالي كأنهما +20 XP.
- مكافأة المدير العام +1,000,000 نقاط ليست نقاط دوري، ولا تتأثر الأرصدة أو الماسات أو المستوى.

## الثماني مهام الأصلية
1. `share_personal_location`: إثبات مشاركة موقع بين حسابين + إيصال XP موقع ضمن محاكي سابق فقط؛ **لا إثبات إنتاجي أو ملكية هاتف حقيقية**.
2. `open_map`: لا منتج إثبات خادمي موقّع مثبت.
3. `share_registered_place`: لا منتج إثبات خادمي موقّع مثبت.
4. `open_saved_place`: لا منتج إثبات خادمي موقّع مثبت.
5. `open_received_place`: لا منتج إثبات خادمي موقّع مثبت.

8. `long_trip`: لا منتج إثبات خادمي موقّع مثبت.

## ما أُنجز في هذا الفرع
- عقد موحد `functions/deda_weekly_original_eight_task_source_gate_NOT_EXPORTED.js` يعكس أسماء المهام الثمانية الأصلية ونوع الإيصال canonical الأصلي ويمنع إدخال المهام الغريبة أو مكافأة المدير أو تعديل XP/ماسات أو إعلان نتيجة فعلية دون إثبات الخادم.
- فحوص مباشرة تقارن مع ملفات DEDA الأصلية `lib/main.dart` ومسار إيصال مشاركة الموقع المؤكد لدى `functions/deda_weekly_stage42_server_share_action_producer_NOT_EXPORTED.js`.
- التشغيل في GitHub Actions محمي من لمس `lib/` و`functions/index.js` و`firestore.rules` و`assets/`، ولا يبني APK ولا ينشر.

**مهم:** هو قيد أمان وفحص مصدر، ليس تشغيل سبعة منتجين خادميين جدد. لا توجد سلطة إنتاج موثوقة للنقاط الكاملة أو حساب PIN/UID عبر هاتفين أو محفظة الجوائز، فلا يصح القول إن الدوري مكتمل أو أن الجوائز تُصرف.

## طريق إكمال النسخة (لا مراحل إضافية دون تقدم فعلي)
- مصدر خادم معتمد لكل مهمة + تدقيق ترحيل XP القديم لمنع الدفع المزدوج، وربط هوية PIN/UID واستعادة الجهاز الجديد بدون تغيير المقتنيات.
