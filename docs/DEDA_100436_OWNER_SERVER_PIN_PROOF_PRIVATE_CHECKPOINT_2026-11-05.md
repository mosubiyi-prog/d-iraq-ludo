## شروط لا يجوز تجاوزها قبل الربط
1. التحقق إن كان كل UID قديم مربوطًا بالفعل بنفس Firebase Auth UID عبر الهاتف الأصلي؛ إذا لم يكن مربوطًا فلا نطلب تحويل UID بصمت ولا نسمح باسترجاعه على أساس رقم/رمز فقط.
