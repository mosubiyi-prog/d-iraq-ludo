## نتائج أولية من قراءة المصدر — ليست أعطالاً مثبتة على الجهاز

- البدء ينتظر Firebase ثم التفضيلات ثم تهيئة المهام قبل runApp؛ يلزم قياس كل خطوة قبل قرار إعادة ترتيبها.
- `_ensureOwnerSessionForAccountKey` يمكن أن يغلق جلسة مدير غير مجهول لاستعادة جلسة المستخدم. لذلك لا يجوز استدعاؤه عالمياً عند كل resume دون سياق وصلاحية القسم.
- توجد حمايات UID/epoch ودورة حياة بالفعل في بعض وحدات الهوية؛ يجب توحيدها مع حفظ حدود الإثبات الحالية، وليس بناء طبقة ثانية تتجاوزها.
- `DedaSocialService.ensurePersonalSession` يكتب الملف الاجتماعي؛ الاسم وحده لا يعني أنه فحص جاهزية للقراءة فقط.
- توجد مهلة 12 ثانية لتسجيل الدخول المجهول في PinAuth، بينما مسار `_ensurePublicUser` الآخر لا يظهر مهلة محلية. لا يكفي إضافة timeout وتكرار تسجيل الدخول: انتهاء انتظار Future لا يلغي عملية المصادقة الأصلية.
- RequestCoalescer وPublicProviderHealth مخصصان صراحة لبحث الأماكن العامة. لا يُعاد استخدام التخزين المؤقت فيهما للأرصدة أو إثبات الملكية أو GPS.

## دفعة المتابعة — إعادة التكوين وأول ربط تجريبي

- أُنشئت لقطة مصدر ثابتة `tools/app_stability/100380-baseline.tar.gz` مع manifest لكل ملف. تحتوي 95 ملف Dart وpubspec/lock و12 صورة PNG أصلية ناقصة من المستودع. الصور مستخرجة من APK 100379 السابق بعد مطابقة بصمة أرشيفه. لا Android أو مفاتيح أو إعدادات Firebase أو APK/AAB في اللقطة.
- أداة الاستعادة تتحقق من بصمة الأرشيف وكل عضو وترفض المسارات غير المصرح بها والروابط واستبدال أي مجلد عمل غير فارغ. أُعيد التكوين مرتين محلياً؛ فرق نسخة التجربة محصور في ملفي القراءة أدناه.
- إصدار Flutter في سجل البناء السابق 3.47.7؛ فحص GitHub الجديد مثبت على نفس الإصدار ويستخدم lockfile دون ترقيات حزم.
- أُضيف `DedaStabilityReadScope`: دمج الطلبات المتطابقة الجارية، مهلة انتظار كلية، محاولة إضافية واحدة فقط لفشل قراءة مكتمل ومصنف كمؤقت، إبطال نتائج الأجيال القديمة، وحد للطلبات المعلقة. لا تخزين مؤقت لنتائج الملكية ولا تكرار لطلب SDK ما زال حياً بعد انتهاء مهلة الواجهة.
- أول ربط محصور بقراءة الهوية في `DedaQa32ActiveAccountScope` خلف `DEDA_STABILITY_IDENTITY_PILOT` الافتراضي false. بقيت استدعاءات إثبات المالك والملكية والإيصال والتحقق النهائي كما هي. وظائف المصادقة والشراء والمنح والرصيد والملاحة لم تُعدل.
- لم تتغير workflows البناء السابقة ولا إعدادات التوقيع. workflow جديد يختبر المرجع والتجربة بمصفوفة منفصلة ولا يصدر APK أو يتصل بحسابات المستخدمين.
- رفضت مراجعة الأمان الآلية بدء Flutter محلياً بسبب محاولة اتصال بعنوان بيانات البيئة السحابية. لم تُكرر المحاولة ولم يُتجاوز الرفض؛ التحقق التنفيذي لهذه الدفعة ينفذ على GitHub المعزول دون أسرار أو مفاتيح.
