## التالي المحدد

راجع تزامن تهيئة الجلسة بين PinAuth وDedaBackend ومسارات الإدارة، ثم صمم تنظيماً يحافظ على حدود كل دور واختبره بمصادقة مزيفة قبل أي ربط. لا تستدعِ `_ensureOwnerSessionForAccountKey` آلياً عند الاستئناف؛ يمكنه إنهاء جلسة الإدارة. لا تعِد تسجيل دخول انتهت مهلة انتظاره بينما عملية SDK الأصلية حية. لا تعد انتهاء القراءة أو أول إطار دليلاً على جاهزية الحساب أو الملكية.

قياسات الزمن الحالية تحققت بساعة مزيفة وبـWidget بسيط، ولا تمثل الهاتف. لا تعِد ترتيب bootstrap استناداً إليها، ولا تدّعِ تحسناً أو سلامة أرصدة إنتاج. قراءات الأجهزة ومقارنة المرجع والتجربة بالأداة نفسها تبقى معلقة حتى تجهيز نسخة الفحص المناسبة.
