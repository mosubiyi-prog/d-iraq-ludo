## Scope and source-of-truth investigation

The existing 100420-derived DEDA source uses DIFFERENT authorities for these user-visible facts:

1. **Ordinary task points:** `DedaTaskEngine` in `lib/main.dart` uses local `deda_task_points_state_v1_{accountKey}` with dated completion keys and award IDs. An already-completed task doesn't need another award on phone replacement. Admin test points are an additional local presentation amount and MUST NOT be credited into the account ledger or to a recovered ordinary account. Normal task points 5, daily login 10, correct traffic answer 5.
2. **Social coins/XP and level:** legacy `deda_social_progress_v1_{accountKey}` is local and is captured verbatim by `DedaLegacyProgressCapture`. Verified progress prototype separately stores `points,coins,xp,earnedDiamonds` in `deda_verified_progress/{accountKey}` after a reviewed, one-time baseline. **A UI level value alone is client-editable; a safe level policy/canonical readback is still missing.** The 100429 snapshot returns `level:null`, not an invented level calculated from possibly mismatched XP.
3. **Earned diamonds:** legacy `deda_diamonds_wallet_v1_{accountKey}` is local. A *separately reviewed historical baseline* can yield `earnedDiamonds` in verified progress, but source values alone never authorize credits.
4. **Gifted diamonds:** `deda_diamond_gift_balances/{originalId}` is a DISTINCT spendable source. Absent record is **unknown**, not automatically 0 when restoring a complete account; never refill gifts from old capture.
5. **General-manager personal diamonds:** `deda_gm_personal_diamond_wallets/{accountKey}` protected by `admin_entry_access`; the distinct admin gift pool MUST NOT be merged with normal earn/gift balances. Source currently displays ordinary + manager but the reviewed spending policy may select the manager personal wallet; don't double-charge.
6. **Weekly task XP:** `deda_weekly_direct_weeks/{weekId}/scores/{originalId}` holds same-week unique `claimedKeys` and `weeklyXp=20*completedTasks` in the reviewed direct-league path. It is **not** a new lifetime XP award when viewed on a new phone.
7. **Traffic quiz UI:** `lib/traffic_quiz_page.dart` saves seen bank, selected five IDs, answers, correct answers, index and completed flag to five SharedPreferences sources under accountKey+day. It creates **100 questions as 20 sign bases × 5 variants**, **four choices per question**. NOTE: User previously asked for three choices in a separate UI decision, but the actual source in this branch has four; this recovery task does NOT modify the quiz UI, and fidelity tests reflect the real installed-code representation.
8. **The backup coordinator** `lib/deda_progress_backup_coordinator.dart` preserves three legacy financial sources as untrusted evidence and does not apply them as wallet totals; `lib/deda_100429_local_task_traffic_evidence.dart` adds read-only local UI evidence capture with exact SharedPreferences keys and account-session staleness guards. Neither is activated as full cross-phone restoration.
