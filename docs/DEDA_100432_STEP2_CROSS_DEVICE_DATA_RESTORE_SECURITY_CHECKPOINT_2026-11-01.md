## Gates preventing falsely claiming completion
- Direct cloud quiz UI backup path is **not activated on a real handset**, because the deployed Firestore UI backup match does not yet exist and app login/startup has not been wired to opt-in controls and trusted authenticated restore. No verified public IP/username/password/session pair was touched.
- Daily tasks, XP/level, ALL diamonds and gift/manager pools are NOT financially migrated. Old local values are untrusted; without authoritative original baselines, global rate-limited ownership and an old-writer fence, adding them would risk inflation and duplicate debit. The reviewed ledger prototype is not an existing active live balance source for most 100340 accounts.
- 100340 old-client anonymous UID assumption means linking original UID to a managed provider on that same old APK would sign that user out when it expects anonymous; require private APK rollout/test and safe downgrade plan first.
- Current app uses some separate users/{uid} fields, and even though same auth UID helps, friends, settings, saved places and accepted gifts must each prove identity and return correctly on two physical devices.
- No **secure** full cross-device 6-digit PIN recovery can be declared without trusted server limit/second factor; managed Firebase Auth with a six-digit password does not eliminate guessing.
- No production changes or APK are authorized by this checkpoint; no Google Cloud billing workaround is implied.
