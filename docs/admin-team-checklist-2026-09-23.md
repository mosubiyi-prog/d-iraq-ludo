# DEDA — إدارة الفريق والصلاحيات

مرجع التنفيذ الإلزامي للنسخة التالية لـ Build 110. لا يتم دمج العمل في `places-v1` قبل مراجعة البنود الأربعة عشر كلها.

- [ ] 1. بيانات العضو الإداري: الاسم، البريد، الهاتف الاختياري، رقم إداري تلقائي، الدور، القسم، المحافظة عند الحاجة، تاريخ الإضافة، ومن أضافه.
- [ ] 2. الأدوار: مدير عام، معاون مدير، موظف، وكيل محافظة.
- [ ] 3. دخول آمن بدعوة/رمز مؤقت مع إلزام تغيير كلمة المرور في أول دخول، من دون تخزين كلمة مرور صريحة.
- [ ] 4. صلاحيات فردية تشغيل/إيقاف: الدعم، طلبات الأماكن، اعتماد/رفض، المستخدمون، البلاغات، التقارير، المحافظات، السجل الإداري.
- [ ] 5. صلاحيات حساسة حصرية للمدير العام: إضافة/حذف إداري، تغيير الدور، تعديل صلاحيات المعاون، إيقاف الحساب، إعدادات حساسة.
- [ ] 6. وكيل المحافظة: المحافظة إلزامية، ووصوله مقيد بمحافظته.
- [ ] 7. حالة الحساب بالنص المعتمد: نشط / متوقف مؤقتًا / معطّل، مع تسجيل خروج من جميع الأجهزة.
- [ ] 8. صفحة تفاصيل العضو: الدور، القسم، المحافظة، الصلاحيات، آخر دخول، تاريخ الإنشاء، آخر تعديل للصلاحيات، الحالة.
- [ ] 9. سجل إداري آلي: اسم المسؤول، الدور، الإجراء، الهدف، التاريخ والوقت.
- [ ] 10. سبب إلزامي للعمليات الحساسة: رفض مكان، إيقاف عضو، تغيير صلاحيات/دور مهم.
- [ ] 11. لوحة مدير عام ببطاقات موبايل مرتبة: الفريق، طلبات الأماكن، الدعم، المستخدمون، البلاغات، المحافظات، التقارير، السجل، الإعدادات.
- [ ] 12. واجهة حسب الصلاحيات، والحماية من الخادم/القواعد أيضًا لا من إخفاء الأزرار فقط.
- [ ] 13. حماية تمنع تعطيل/إزالة آخر مدير عام فعّال، مع تسجيل تغييرات الإدارة.
- [ ] 14. بحث وفلاتر حسب الاسم/الإيميل، الدور، المحافظة، وحالة الحساب.

## صياغة الحالة المعتمدة
- نشط
- متوقف مؤقتًا
- معطّل

## حدود هذه الحزمة
- لا تغيير على فحص رقم هاتف المستخدم العادي في هذه الحزمة.
- Build 110 تبقى محفوظة كنقطة رجوع قبل نظام الإدارة.
