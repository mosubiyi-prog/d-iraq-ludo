# DEDA — إدارة الفريق والصلاحيات

مرجع التنفيذ الإلزامي للنسخة التالية لـ Build 110. تم تنفيذ البنود ومراجعتها على فرع العمل المعزول `admin-team-work-2026-09-23`. لا يتم دمجها في `places-v1` إلا بعد اجتياز التحقق النهائي.

- [x] 1. بيانات العضو الإداري: الاسم، البريد، الهاتف الاختياري، رقم إداري تلقائي، الدور، القسم، المحافظة عند الحاجة، تاريخ الإضافة، ومن أضافه.
- [x] 2. الأدوار: مدير عام، معاون مدير، موظف، وكيل محافظة، مع توافق تلقائي للحساب الإداري القديم.
- [x] 3. دخول آمن بدعوة/رمز مؤقت، مع إلزام تغيير كلمة المرور في أول دخول، من دون تخزين كلمة المرور المؤقتة كنص صريح في Firestore.
- [x] 4. صلاحيات فردية تشغيل/إيقاف: الدعم، طلبات الأماكن، المراجعة، الاعتماد، الرفض، المستخدمون، البلاغات/التقارير، المحافظات، السجل الإداري؛ مع ربط الصلاحيات التابعة تلقائيًا.
- [x] 5. الصلاحيات الحساسة حصرية للمدير العام: إنشاء/حذف عضو إداري، تغيير الدور، تعديل الصلاحيات والحالة، إعادة رمز الدخول، وإدارة الجلسات. استرجاع حسابات المستخدمين الحساسة محصور بالمدير العام أيضًا.
- [x] 6. وكيل المحافظة: المحافظة إلزامية، وطلبات الأماكن مقيدة بمحافظته من الواجهة وقواعد Firestore. لا تظهر له بيانات المحافظات الأخرى أو الأقسام العالمية غير القابلة للتقييد بالمحافظة.
- [x] 7. حالة الحساب بالنص المعتمد: نشط / متوقف مؤقتًا / معطّل، مع إمكانية تسجيل خروج العضو من جميع الأجهزة وسحب الجلسات.
- [x] 8. صفحة تفاصيل العضو: الدور، القسم، المحافظة، الصلاحيات، آخر دخول، تاريخ الإنشاء، من أضافه، آخر تعديل للصلاحيات ومن عدّلها، والحالة.
- [x] 9. سجل إداري آلي: اسم المسؤول، الدور، الإجراء، الهدف، السبب عند الحاجة، والتاريخ/الوقت. يشمل تغييرات الفريق، الدعم، طلبات الأماكن، مشاهدة حساب المستخدم، البلاغات، واسترجاع الدخول.
- [x] 10. سبب إلزامي للعمليات الحساسة: رفض/طلب تعديل مكان، إيقاف/تعطيل عضو، تغيير دور أو صلاحيات أو حالة، حذف عضو، سحب الجلسات، إعادة رمز دخول، ورفض استرجاع الدخول.
- [x] 11. لوحة المدير العام ببطاقات موبايل مرتبة: الفريق والصلاحيات، طلبات الأماكن، الدعم، استرجاع الدخول، المستخدمون، البلاغات، المحافظات، التقارير، السجل الإداري، والإعدادات.
- [x] 12. الواجهة حسب الصلاحيات، مع حماية فعلية في قواعد Firestore وCloud Functions، وليس إخفاء الأزرار فقط. الجلسات الإدارية الموجودة مسبقًا تُوجَّه للوحة الصلاحيات الجديدة أيضًا.
- [x] 13. حماية تمنع تعطيل/إزالة آخر مدير عام فعّال، وتمنع حذف الحساب الإداري الحالي أو إيقاف جلسته من نفس الحساب، مع تسجيل تغييرات الإدارة.
- [x] 14. بحث وفلاتر حسب الاسم/البريد/الرقم الإداري، الدور، المحافظة، وحالة الحساب.
