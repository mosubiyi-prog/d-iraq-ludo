- **Firebase Auth Emulator issues UNSIGNED TEST ID tokens.** Its Functions Emulator can label certain crafted JWTs as `auth:VALID` (observed in first Stage51 run), unlike real production cryptographic verification. The private Auth-only diagnostic now additionally verifies the Auth Emulator account exists and email/provider match; this is QA fixture protection, **NOT cryptographic token verification and does NOT establish physical device identity**. A forged JWT with sufficient claims referencing a real emulator account may still be accepted; never describe emulator success as protection against production forgery.
