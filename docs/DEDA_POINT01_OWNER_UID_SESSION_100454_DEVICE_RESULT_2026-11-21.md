- `lib/deda_pin_auth.dart::createAccount` أصلاً ينشئ Firebase anonymous UID ويحفظ PIN في Firestore، **ولا ينشئ وسيلة Email/Password لذلك UID**.
- `tools/app_stability/app_package/bind_owner_session_only_100454.py` أدخل `DedaLoginHandoff` الذي يستدعي `lib/deda_step2_linked_owner_firebase_port.dart::signInOriginal` باستخدام `signInWithEmailAndPassword(account@deda-login.invalid, pin)`؛ يفترض مزوداً مربوطاً مسبقاً.
- التدقيق الحقيقي الموثق بتاريخ 2026-11-13 أثبت Auth A/B/C موجودة بلا بريد أو Google أو مزود آخر مرتبط في ذلك التاريخ. لا يدّعي هذا الملف فحص Auth حيّاً جديداً بتاريخ 2026-11-21.
- الأهم: `deda_account_directory.createdUid` يشير إلى B، والآيدي الأصلي يشير إلى A، والمسار الاجتماعي يشير إلى C. إثبات `_sparkOriginalUidServerProof` الحالي يطلب مساواة مُصدِر الدليل ومالك الآيدي مع UID واحد؛ لذلك حتى ربط مزود دخول بواحد منها وحده **لا يحقق كامل شروط الأهلية**.
- وظائف الحماية والغرفة الموحدة `functions/deda_unified_room_*` متوقفة افتراضياً وتفتقد تفويض ملكية مستقل على الإنتاج. اختبارات المحاكي لا تفوّض الوصول إلى بيانات حقيقية.

## قرار تنفيذ إلزامي قبل APK آخر
**NO-GO لإعادة بناء 100454 أو تعليم المستخدم بإعادة PIN**. لن تُستعمل `signInAnonymously` أو حساب Google جديد أو UID D كبديل لملكية A/B/C. لا نشر Play ولا تغيير Firebase/Auth/Rules أو جلسات أو أرصدة أو هدايا أو آيدي على التخمين.

**العملية الوحيدة القادرة على فك الحاجز:**
1. تأكيد رسمي مستقل لملكية الحساب وربطه بخارطة A/B/C لدى جهة مخوّلة (ليس رمز PIN وحده أو ملكية الخط وحدها، بل قرار استحقاق قابل للتدقيق).
2. نسخ احتياطية قبلية وقراءة خادمية حيّة لأصول Auth وأرقام UID المرجعية ومسارات الدليل والآيدي الاجتماعي والإدارة، مع منع أي تغيير عند اختلاف مصدر سابق.
3. بجهة خادمية موثوقة وصلاحية Firebase Admin الرسمية، تمكين مصادقة دائمة **لنفس الهوية المصرّح بها** أو ربط حساب منطقي مُفوض بها، لا اختيار UID الأقدم تلقائياً، مع صلاحيات منفصلة لكل مجال.
4. اختبار رجوع فعلي على الحساب قبل أي تحديث هاتف أو عملية أصول؛ سجل تدقيق ومراجعة صلاحيات Firestore القديمة، ولا تُعدل قيود الأرصدة/المشتريات/الإدارة دون أدلة نطاقية.
5. بعدها فقط فحص الهاتف ذاته: UID والجلسة، الآيدي الأصلي والمميز، الأصدقاء، الدوري، الإدارة، الهدايا والرصيد والتقدم.
