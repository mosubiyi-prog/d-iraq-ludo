## ما أُضيف
1. `lib/deda_daily_user_task_display.dart`: حارس توافق واجهة المستخدم الحالية مع إعدادات المهام العامة المنشورة، دون أي منح مكافأة.
2. متى يظهر عنوان عربي جديد؟ فقط إذا منشور من المجموعة العامة المخصصة، وبياناته صحيحة، وتوقيت `publishedAt` الخادمي بين منتصف الليل و15 دقيقة، وaction يساوي المعرف الحالي، وtargetCount=1، والمكافأة الأصلية `points/5`.
3. أي تغيير بمبلغ المكافأة أو الماس/العملات أو عدد مرات الإنجاز أو نوع المهمة أو الرابط الخارجي لا يغير بطاقة المستخدم ولا محركها بعد؛ غير مقبول إظهار وعد مكافأة غير مدعوم من محرك قديم.
4. تعديل `lib/main.dart` محدود باستيراد الملفات، وفتح اشتراك Firestore العام في وضع المعاينة فقط داخل شاشة `DedaDailyTasksPage`، وتغيير نص العنوان فقط عبر حارس التوافق. أزرار المهام والأحداث والتقدم واستلام المكافأة بقيت كما هي.
5. في وضع اللغة الإنكليزية أو عند خطأ الشبكة/صلاحيات القراءة أو غياب مستند منشور صالح، تبقى البطاقة الأصلية. لا يظهر عنوان مدير العام من مسودات أو معاينات الإدارة.
6. استخدام `publishedAt` يعني إثبات وقت **نشر سابق**، وليس ساعة حالية أو إشارة لاستحقاق نقاط. صرف المكافآت يستلزم خادمًا بساعة موثوقة وسجل ذرّي يمنع التكرار.
