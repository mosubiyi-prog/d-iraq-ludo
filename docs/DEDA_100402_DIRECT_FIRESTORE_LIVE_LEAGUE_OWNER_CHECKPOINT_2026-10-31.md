# DEDA 100402 — تم تفعيل قواعد الدوري على Firebase الحقيقي

المالك طلب نتيجة فعلية بعد 13 يوماً من التأخير: دوري بسيط لحوالي 20 مستخدماً، نفس +20 XP مستوى بعد كل استلام مكافأة مهمة، لا حساب نقاط جديد ولا تعقيد زائد. ممنوع نشر Play أو دفع أو صفحة دولة.

## نتائج مؤكدة بعمليات حقيقية
- مصدر التطبيق 100396 التاريخي لم يُعدل. كل التغييرات بفرع deda-100402-firestore-direct-league-first-apk-2026-10-31.
- قواعد Firestore المباشرة: حساب خاص مخفي، وبطاقة ترتيب عامة واحدة لكل حساب/أسبوع، ويزيد المجموع +20 فقط بعد إضافة مهمة جديدة. منع تكرار المهمة ضمن اليوم والأسبوع، سقف 56 عملية/1120 نقطة للأسبوع. نقاط المستوى والماسات غير قابلة للتعديل عبر هذا المسار.
- أسبوع أول مقرر السبت 31 أكتوبر 2026 الساعة 06:00 صباحاً بتوقيت العراق، تجميد السبت التالي 00:00–06:00.
- اختبارات محاكي حسابين: GitHub Actions 41151247370 نجحت، منها القراءة المشتركة، وعدم مضاعفة المهمة، وعدم إمكان تحريف رصيد المنافس.
- قواعد الإنتاج تختلف عن ملف المستودع. تمت إضافة فقط قواعد الدوري إلى **النص المنشور الفعلي**، مع إجراء محاكي كامل للقواعد المدمجة. GitHub Actions 41151399255 نجح، ويشمل التحقق بعد النشر من تطابق النص الحي مع النص المختبر.
- الخادم Cloud Functions لم ينشر ولم يعد مطلوباً لتسجيل وعرض النقاط. مشروع Firebase الأصلي deda-25b88، ولا ربط فوترة أو Play.
- واجهة ربط Flutter المباشرة: lib/deda_weekly_firestore_direct_bridge.dart، تلقائياً بعد النجاح الفعلي +20 XP، مع مراجعة الحساب وقائمة أعلى 10 ومركز المستخدم والتحديث الدوري وإعادة محاولة الإرسال بنفس يوم بغداد.
- التوقيع الأصلي/حزمة com.diraq.ludo.d_iraq_ludo قيد بناء صاحب الجهاز على GitHub Actions، ويُعتمد فقط بعد ظهور artifact واجتياز الفحص.

## ما بقي قبل وصفه شغالاً بين هاتفين
- APK موقّع قابل للتنزيل، اختبار على الجهاز الفعلي، استلام مكافأة مهمة بحساب A، ظهور +20 في ترتيب حساب B، منع الاستلام ثانية، وفحص إغلاق التطبيق والإنترنت.
- جوائز الماسات التلقائية والإدارة الحية لم تُفعل في 100402؛ لاحقاً دون تلاعب بنظام المستوى.
- الآخرون يجب أن يستعملوا APK الذي يدعم إرسال نقاط Firestore المباشر ليبدأ تسجيل مهامهم بالدوري.

قرار المالك: لا إعادة لنفس شاشات اختيار دولة Google Cloud. لا ادعاء باكتمال التجربة على جهازين دون اختبار صاحبه.
