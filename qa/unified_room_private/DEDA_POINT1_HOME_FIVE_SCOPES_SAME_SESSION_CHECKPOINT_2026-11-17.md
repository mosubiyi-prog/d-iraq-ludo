## تنفيذ موثق
1. أُكمل `lib/deda_unified_room_runtime_readonly.dart` بإضافة `readHomeSections()` لتجميع الطلبات الخمسة `profile`, `original_id`, `premium_id`, `friends`, `league` عبر استدعاء Cloud Functions الموجود. كل طلب يحمل اسم المجال وحده، ولا يرسل UID تاريخياً أو رقم هاتف أو PIN.
2. تُلتقط بصمة جلسة Firebase Auth الحالية قبل الطلبات، وتُفحص بعد اكتمالها، فإذا تبدل UID أو جيل الجلسة أثناء أي طلب تُرفض المجموعة كلها. تبقى نتائج كل مجال مستقلة: `HOLD` ليس صفر أصدقاء أو نقاط ولا آيدي بديل. البيانات لا تُكتب في أي ملف شخصي أو رصيد.
3. صار `preflightOnHome()` يستدعي التجميعة ذات الجلسة الواحدة، بدلاً من فحص `profile` وحده، عبر وصلة `HomePage` المحمية الموجودة سابقاً. عند الإغلاق الافتراضي `DEDA_UNIFIED_ROOM_READ_ONLY_LIVE=false` لا يحدث اتصال ولا تأثير على الواجهة.
4. فحص Flutter الموجود `test/deda_unified_room_runtime_readonly_test.dart` صار يتحقق من مجالات الصفحة الخمسة وعودة النتيجة الفارغة بالوضع المغلق، مع استمرار اختبارات رفض بيانات الحقول غير الصحيحة.

## أدلة الفحص الصريحة
- جرى جلب **نفس الملفات المحفوظة في GitHub** للحارس الخادمي وخدمة إصدار التصاريح واختباراتهما؛ شُغلت 35 حالة أصلية في **مُشغِّل V8 محلي يدعم `node:test` و`assert` بصورة محاكاة**: **35/35 PASS**. هذا ليس GitHub Actions ولا تشغيل Node test runner الأصلي ولا Firebase Emulator.
- شملت الفحوص رفض المراجعات المصطنعة، صلاحيات المجال غير المخول، عدم اشتراط جلسة B التاريخية، رفض تبديل جلسة القارئ، رفض تبديل المصدر A/B/C، ومنع النقل المالي/الهوية.
- لا توجد نتيجة موثقة لهذه الجولة من **GitHub Actions** أو بناء Flutter APK أو محاكي Firestore القواعد. يجب عدم ذكر PASS لها بلا سجل تشغيل مثبت.
- كل التغييرات في هذه الجولة محفوظة بفرع معزول؛ لا نشر Play، لا تغيير UID أو قواعد Firebase الإنتاجية، ولا تعديل للممتلكات الحقيقية.

## القيد الحقيقي الذي يمنع إعلان الإنجاز على الهاتف
- Cloud Function `dedaUnifiedRoomReadOnlyV1` **ما زالت معطلة** `enabled:false` في `functions/index.js`، وFlutter مقفل `defaultValue:false`. خدمة الإصدار غير مفعّلة؛ سجل الملكية المستقل الحقيقي لم يُعتمد ولم يُعطِ إذناً إنتاجياً لأي حساب A/B/C.
- تجميع قراءة موجز الأقسام الخمسة **لا يساوي إصلاح قائمة الأصدقاء الكاملة أو بطاقة الدوري أو الآيدي بالواجهة**. الوصلة لا تستبدل عناصر الواجهة ولا تتجاوز صلاحيات النسخ القديمة.
- لم تُنفَّذ تجربة حساب حقيقي أو هاتفين؛ أي محاولة تشغيل دون إثبات مستقل للملكية قد تعرّض بيانات مستخدم آخر، لذا تبقى الحماية مغلقة.
